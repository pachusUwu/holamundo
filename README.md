## Entorno configurado

| Componente | Detalle |
|---|---|
| Editor | Visual Studio Code |
| Extensiones | C/C++, C/C++ Extension Pack, Code Runner |
| Compilador | g++ 16.1.0 (MSYS2 UCRT64) en `C:\msys64\ucrt64\bin` |
| Terminal | PowerShell integrada de VS Code |

## Compilar y ejecutar

```powershell
g++ src/main.cpp -o src/holamundo.exe
.\src\holamundo.exe
```
